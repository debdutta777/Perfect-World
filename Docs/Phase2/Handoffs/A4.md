## 5. Expected `SchoolLife` Contract (A3) Binding

Because Order A3 (`SchoolLife.h`) is not yet merged in this worktree, `SchoolLifeContent.h` defines the minimal portable trigger and outcome structs:
- `SchoolLifeTrigger`: carries `bGrewUpInCare`, `Stream`, `CurrentTermId`, `CurrentZone`, `MinuteOfDay`, and `ArcProgress` (`map<arcId, currentSceneId>`).
- `SchoolLifeOutcome`: carries `bOk`, `Error`, `ArcId`, `SceneId`, `ChoiceId`, `NextSceneId`, `ResolutionId`, `OutcomeTextKey`, `ElapsedMinutes`, and `Consequence` (`SchoolSceneConsequence`).
- `QueryAvailableSchoolScenes(catalogue, trigger)`: returns all `SchoolSceneNode*` matching the player's origin (`family` vs `care_home`), active term, zone, and minute window.
- `ResolveSchoolSceneChoice(catalogue, arcId, sceneId, choiceId, bGrewUpInCare)`: validates origin compatibility and returns the deterministic `SchoolLifeOutcome`.

**Integration snippet for A3 (`SchoolLife.cpp` / `WorldSchoolDay.cpp`):**
```cpp
#include "SchoolLifeContent.h"

// When advancing a school/home slot in A3:
const SchoolLifeOutcome outcome = ResolveSchoolSceneChoice(
    schoolSceneCatalogue, arcId, sceneId, choiceId, state.Origin.GrewUpInCare);
if (outcome.bOk)
{
    arcProgress[std::string(arcId)] = outcome.ResolutionId.empty()
        ? outcome.NextSceneId
        : ("resolved:" + outcome.ResolutionId);
}
```

## 6. Relationship & Thread Event Mappings (`Relationships.h` / `Threads.h`)

When `ResolveSchoolSceneChoice` returns `outcome.bOk == true`, apply `outcome.Consequence` to `RelationshipsState`, `EventLog`, and `ThreadInstance`:

```cpp
// 1. Record the remembered RelationshipAct and fair EventLog entry:
const RelationshipActResult relResult = RecordRelationshipAct(
    relationshipsState,
    eventLog,
    RelationshipAct{
        .ActorId = "person.player",
        .TargetId = outcome.Consequence.TargetPersonId,
        .Kind = outcome.Consequence.ActKind,
        .When = state.Clock.Now(),
        .PlaceId = currentNode.Schedule.Zone,
        .EventType = outcome.Consequence.RelationshipEventType,
    });

// 2. If outcome.Consequence.ThreadEventType is non-empty, emit the thread event for AdvanceThread:
if (!outcome.Consequence.ThreadEventType.empty())
{
    EventRecord threadEvent;
    threadEvent.When = state.Clock.Now();
    threadEvent.Type = outcome.Consequence.ThreadEventType;
    threadEvent.PlaceId = currentNode.Schedule.Zone;
    threadEvent.Parties = {"person.player", outcome.Consequence.TargetPersonId};
    eventLog.Append(std::move(threadEvent));
}
```
