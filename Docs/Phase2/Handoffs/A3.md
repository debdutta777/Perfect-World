## Design

Both screens are Slate widgets that hold no rules. They talk to the frozen contract only through `PWClassA3::ILessonBridge`, whose methods map one to one onto `QuerySchoolPeriod`, `QuerySchoolLesson`, `OpenSchoolLesson`, `QuoteSchoolLessonAction`, `ChooseSchoolLesson` and `CloseSchoolLesson`. Skill, world seed and known alternatives belong to the bridge, never a widget. Every price on screen is a core quote taken for that decision right now; every refusal is the core's code shown as words (unknown codes read as neutral text, never as the key). The screens never read `InvestigateCause::Fault`, `CoordinateFact::Critical`, `CoordinateCaseDef::Constraint` or `::Seam` for display. The only fault-derived value is the positive/negative reading of a test the player has already run, which is what running it reveals.

States of the shell (one panel, rebuilt on every refresh): idle (choose Foreground / Routine / Attend with the core's availability and reasons, choose the goal, Start), playing (the structure body), finished (typed outcome, grade, failures in words, Record), closed. Leave early is offered while it is legal and charges `units spent x 5` minutes capped at period minus one (the core refuses to cancel a finished foreground lesson, and the screen mirrors that by hiding the button; the core remains the authority).

Meaningful differences between the structures:
- **Investigate**: an open loop. Tests are listed with kind, the causes each would implicate, and the quoted price; a run test shows its reading and the evidence log shows which causes still stand. Conclude by naming a cause (cost 0) or reporting honestly (cost 0). A cause that would be a guess while others stand says so; a report when one cause already stands says so. Price badges include the role and scarce-resource effects in words.
- **Coordinate**: four ordered beats. Assign (pencil a draft task by task against live capacity and suit, then commit once at the quoted price; an incomplete draft is never sent), Exchange (talk to each classmate once, priced, learning only the facts the exchange reveals), Settle (five resolutions, each quoted, Leave is free and settles nothing), Submit (check or submit as it stands). The draft is widget-local, not authoritative.

Keyboard and controller: every action is a real `SButton` (via `PWUI::MakeContentButton`/`MakeButton`), so Slate navigation (Up/Down, D-pad, left stick) and Enter/A work; focus is restored to the nearest enabled action after every rebuild and the body scrolls to the focused row. G / right shoulder change the goal and M / left shoulder the mode (idle only); Esc, B and the menu button go back. No animation anywhere, so reduced motion holds. Density follows the same switch as the quest window (compact below 760 logical units), re-checked each tick; the body scrolls and Back and Leave early sit outside the scroll box, so they cannot leave the screen at 853x480 or 150% text. Back never closes a running lesson; it only leaves the screen (see assumptions).

### Two scene-dispatch entries (anchor: the switch over `binding.Structure` in the lesson panel factory; A2 owns `Model` and `Explain`)

```cpp
case PerfectWorld::SchoolStructure::Investigate:
    return SNew(SPWClassInvestigate)
        .Bridge(LessonBridge)                       // TSharedPtr<PWClassA3::ILessonBridge>
        .Space_Lambda([Self]() { return SPWPauseMenu::PauseSpaceOf(Self); })

    return SNew(SPWClassCoordinate)
        /* the same five arguments */;
```

Interacting with a classroom desk while `QuerySchoolLesson(state).Run` is set must reopen the panel for `Run->Binding` (Back does not close the lesson, so this is how a player resumes it). If the run belongs to another binding the panel says so and offers only Back.

### Command delegates: one world-backed bridge (replaces `FCoreLessonBridge` in the game)

`FCoreLessonBridge` calls the contract directly over borrowed state and is for tests and a harness. In the game implement `PWClassA3::ILessonBridge` over the reducer, using the P2C notes' command wrappers, one atomic transaction each:

```cpp
class FWorldLessonBridge final : public PWClassA3::ILessonBridge
{
    // GetBinding/GetCatalogues: the A1 binding for this desk and the immutable SchoolSessionCatalogues.
    // QueryPeriod  -> PerfectWorld::QuerySchoolPeriod(State.SchoolSessions, State.DayLoop, Binding, Cats)
    // QueryLesson  -> PerfectWorld::QuerySchoolLesson(State.SchoolSessions)
    // QuoteAction  -> PerfectWorld::QuoteSchoolLessonAction(State.SchoolSessions, Cats, Session, Action)   (read only, no command)
    // OpenLesson   -> Submit(SchoolLessonOpen{Binding.Id, Mode, Goal}); the reducer resolves skill from the R9 owner and the seed.
    // ChooseAction -> Submit(SchoolLessonChoose{Session, Action});
    // CloseLesson  -> Submit(SchoolLessonClose{Session, bCancel, ElapsedMinutes});
    // ResolveText  -> A1's text table for Binding.TitleTextKey/BriefTextKey/RoleTextKey (this order's table only holds phase2.a3.*).
};
```

Map a rejected command's code to `SchoolIssue{Code, Detail}` unchanged so `IssueText` keeps working; the core's `SchoolSessionResult::Events` go to `ApplyActivityCredits` inside the same transaction exactly as the P2C notes say (the screen only needs `Ok()`/`Issue`/`ReadyToClose`). After any change made elsewhere call `Panel->RefreshModel()`.

### Focus restoration

`ReturnFocus` is set on the widget that opened the panel; `RequestClose()` runs `OnClose` first (the host may drop the panel) and then focuses it with `EFocusCause::SetDirectly`. If the host prefers the pause-menu pattern, omit `ReturnFocus` and call `PWUI::FocusWhenReady(AsShared(), RestoreTarget)` in the close handler, as `SPWPauseMenu::CloseQuests` does. `OnLessonClosed` fires once, after the core accepted Close or Leave early; the host normally closes the panel there.

### CMake / build lists

None for the core (no portable files). Unreal discovers the new `.cpp` files under `Private` by itself; if an explicit source list exists, add the five new `.cpp` files. No `.Build.cs` change (Slate, SlateCore, PerfectWorldCore are already dependencies).

### Expected content-manifest changes

None. `Data/Text/en/phase2_a3.json` is outside `Data/Content`. It is not loaded at run time yet: the on-screen strings come from the `A3T` table at the top of `SPWClassInvestigate.cpp` (each entry is a `LOCTEXT` whose key is the JSON key), and the JSON was generated from that table, so the two cannot drift. Regenerate if wording changes (the generator is not part of the order).

## Unresolved assumptions

1. Back leaves the screen but keeps the lesson open (the core has no "suspend"); the host must make the desk reopen the panel. Alternative: make Back mean Leave early; say if you prefer that.
2. Leave-early minutes = `units spent x 5`, capped at period minutes minus one. The 5 is the core's unit length (nine five-minute units per period); it is a constant in the shell, not read from the core, which does not expose it.
3. Binding title/brief/role text (A1 keys) must come from the bridge's `ResolveText`; unknown keys leave those lines blank and the title falls back to "Lesson".
4. Diagnosing an already ruled-out cause is left enabled (the core allows it and grades it); the row says it is ruled out.
5. Cost-short rows are disabled rather than refused-on-press, so they are skipped by focus navigation; their price and "Needs N, M left" stay visible.
6. The automation tests read `Data/Content` from `FPaths::ProjectDir()`, like `UPWContentSubsystem`; they need the editor opened on this project.

## First-compile risks

- Unity build: all file-local names carry `A3I`/`A3C`/`A3Tst` prefixes and the shared names are in `PWClassA3`, `PWClassInvestigate`, `PWClassCoordinate`; A2's files use `PWClassModel`/`A2`. The `A3T` macro is `#undef`ed in the same file. Still the likeliest class of failure if another order picks the same names.
- `SchoolSessions.h` pulls `Assessment.h`, `DayLoop.h` and the structure headers into Unreal translation units for the first time; the `/Zs` pass shows no clash with engine macros in these three files, but another TU that includes them after an engine header that defines a conflicting macro could differ.
- `LOCTEXT` entries are built inside a function-local static table; if localisation gathering is later run, keys appear under namespace `PerfectWorldClassA3`.
- `SBox/SScrollBox` slot lambdas capture `this` raw, as the quest panel does; the body widgets never outlive the shell.
- `FPWClassLessonClosed` is a global delegate type (declared with `DECLARE_DELEGATE_OneParam`); the name must stay unique across the module.
- The tests construct panels without a window; `FocusWhenReady` registers an active timer that is harmless headless, as in the journal tests.
